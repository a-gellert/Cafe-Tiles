# Cafe Tiles

Казуальная HTML5-игра для [Poki](https://poki.com): маджонг-«3 в ряд» (3 Tiles) с обслуживанием клиентов кафе и украшением своего кафе.
Движок Defold 1.14, Poki SDK 4.1.0. Работает в портретной (телефон) и альбомной (десктоп) ориентации.

## Как запустить

1. Открыть `game.project` в Defold 1.14+.
2. `Project → Fetch Libraries` (подтянется Poki SDK).
3. `Project → Build` — запуск на десктопе (реклама там выдаётся сразу как «успешная»).
4. `Project → Build Poki HTML5` — сборка в браузере с Poki Inspector.
5. `Project → Bundle → Poki` — архив для загрузки на Poki.

Без редактора (Git Bash, из корня проекта):

```sh
sh tools/build_web.sh          # debug wasm-web в bundle/web
sh tools/build_poki.sh         # release + poki.zip (≈1.4 МБ)
```

## Игра

- На столе слоями лежат плитки с едой. Брать можно только верхние (не накрытые) плитки.
- Плитка уходит в поднос на 7 ячеек. Три одинаковых блюда собираются в заказ.
- У стойки стоят до трёх гостей, над каждым бабл с заказом (1–3 блюда), с 6-го уровня ещё шкала чаевых. Гости никогда не уходят без заказа.
- Собранная тройка уходит гостю с таким блюдом (x2 монет и чаевые). Если блюдо никто не заказывал, тройка встаёт на витрину и тоже приносит монеты.
- 7 плиток без тройки = «завал на кухне». Первый завал уровня шеф разбирает бесплатно (3 плитки на полку над подносом), дальше второй шанс за рекламу или монеты.
- Уровень пройден, когда стол, поднос и полка пусты. Звёзды — за долю троек, отданных гостям.
- Монеты (блюда + чаевые + бонус уровня) тратятся на декор кафе. Каждый уровень декора даёт +5% монет.
- Задания шефа (3 активных, награды монетами и бустерами), VIP-гости с короной (платят больше), сложный уровень каждые 5 уровней (бонус x1.5), звёздный сундук и серия побед.
- Комбо: быстрые тройки подряд дают монеты сверху и слова-похвалы. Золотые плитки платят бонус, часть закрытых блюд прячется под колпаком до освобождения.
- Подарки за минуты игры (на каждый заход: 75 с, 200 с, 6, 9, 12, 15 мин, дальше каждые 4 мин).

## Монетизация (соответствие концепт-документу)

| Механика из концепта | Реализация |
|---|---|
| Ускорение заказов (rewarded) | Бустер «Срочный заказ»: гость сразу получает весь заказ. 1 бесплатный, дальше за видео |
| Второй шанс (rewarded) | Кнопка в попапе «Завал на кухне», до 2 раз за уровень |
| Бонусная валюта (rewarded) | Кнопка «x2» на экране победы |
| Отмена / Перемешать | 3 и 2 бесплатных, дальше за видео |
| Продолжить за монеты | При завале, без рекламы: 40 + 3·уровень монет, до 2 раз за уровень |
| Межуровневая реклама | `commercial_break` перед уровнем (с 5-го уровня, частоту ограничивает Poki) |
| Sticky banner | В игре не делается: на Poki баннеры показывает сама платформа вокруг игры (и в портрете на мобильных) |
| Кросс-промо «Другие игры» | Кнопка в меню, `poki_sdk.open_external_link`, URL в `game.project → [cafe] more_games_url` (пусто = кнопка скрыта) |

## Структура

```
main/modules/   чистая логика без Defold API в игровых правилах
  session.lua   уровень: поднос, полка, гости (и VIP), заказы, бустеры, события для анимаций
  missions.lua  задания шефа: 3 активных, прогресс, награды
  board.lua     слои плиток, перекрытия, «решаемая» раздача типов
  levels.lua    кривая сложности и процедурные раскладки
  config.lua    константы баланса      decor.lua  декор и рейтинг кафе
  progress.lua  сохранение             i18n.lua   7 языков (en ru es pt de fr tr)
  poki.lua      обёртка Poki SDK       audio.lua  звук и музыка
  layout.lua    виртуальный холст (портрет 720x1280 / альбом 1600x900)
main/gui/       интерфейс целиком из кода (game.gui пустой, только атлас и шрифт)
  game.gui_script  контроллер: экраны, поток уровня, ввод, автоплей
  game_view.lua    экран игры        menu_view.lua  меню-кафе
  popups.lua       попапы            cafe_view.lua  интерьер по уровню декора, анимация покупки
  meta_view.lua    уровень кафе, цель «следующее украшение», превью кафе
main/render/    рендер: GUI в виртуальных координатах на всё окно
tools/          генераторы ассетов, симуляция баланса, смоук-тест в браузере
docs/KNOWLEDGE_BASE.md  дизайн, баланс, проверки, журнал изменений
```

Графика, звуки и шрифт генерируются скриптами (`tools/gen_sprites.js`, `tools/gen_sounds.js` — нужен `npm install --prefix tools`, `tools/gen_font.js`). Шрифт Nunito Black (SIL OFL 1.1). Подробности и порядок проверки: [docs/KNOWLEDGE_BASE.md](docs/KNOWLEDGE_BASE.md).
